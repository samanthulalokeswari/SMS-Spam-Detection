# SMS Spam Detection System

## Overview

An AIML project that classifies SMS messages as spam or legitimate (ham) using machine learning and an interactive Streamlit dashboard.

## Features

- SMS data preprocessing
- Text feature extraction using TF-IDF
- Machine learning classification
- Spam and ham prediction
- Model evaluation
- Interactive Streamlit dashboard

## Dataset

UCI SMS Spam Collection Dataset: [https://archive.ics.uci.edu/dataset/228/sms+spam+collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection)

The dataset contains SMS messages labeled as `ham` (legitimate messages) and `spam` (unwanted messages). The dataset file is available in the `data/` directory.

## Tech Stack

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit
- Joblib

## Setup

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Run the project

Train the model:

```powershell
python train_model.py
```

Launch the dashboard:

```powershell
python -m streamlit run app.py
```

## Model Evaluation

Refer to `metrics.json` for the evaluation results generated by the project.

## Limitations

Predictions may be inaccurate for messages that differ significantly from the training data.
